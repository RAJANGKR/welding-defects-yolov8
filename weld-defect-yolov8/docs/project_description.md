# Project Description

This project presents a practical deep learning framework for the multi-class detection of surface weld defects from conventional visible-light images. The detection problem includes three defect classes: crack, porosity, and spatter.

The implementation is based on YOLOv8 and was developed in Python. The project is structured for reproducibility and academic presentation, with separate scripts for dataset validation, training, evaluation, and prediction.

The repository is suitable for:

- academic GitHub publication
- conference or journal supplementary material
- demonstration of a computer vision workflow for weld inspection
- extension toward real-time industrial inspection systems
